# Site audits

Dated UX/workflow audit reports produced by the **Agent Audit Team** skill
(`.claude/skills/audit-team`). Each run reads the git history, `docs/WORKFLOWS.md`,
and the previous reports here, then writes a new `YYYY-MM-DD-audit.md`.

This folder is the continuity trail: it records what was recommended, what has
since been built, and what's still open — so every audit builds on the last
instead of starting from scratch.

To run one: ask Claude to "run the audit team" (or `/audit-team`).
