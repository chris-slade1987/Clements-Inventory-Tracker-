## 1. Patterns in what we keep fixing

179 changes shipped since the last audit. Grouped by the kind of fix, the same few problems keep returning:

| Pattern | Changes | Symptoms we hit this month |

### The systemic fixes these point to

1. **One period/close calendar** (fixes A). A single ET-aware `Period` service: what month/quarter is "open" for each duty, when it closes, and grace rules set by leadership on a screen (not in code). Every to-do, sweep, reminder, scorecard and default reads it. Month-end/quarter-end becomes a visible **close** step ("October is open until Fri 11/6 — 3 items outstanding").
2. **One sign-off engine** (fixes B). Shared states *draft → released → signed → filed*, with: lock on first signature, signer order, atomic one-time links with expiry, reopen that archives (never erases) signatures, standard notices (signer, HR, "revised" copies), and a **"My signed documents"** list for every employee. Migrate the six flows onto it one at a time.
3. **One obligations ledger + leadership exceptions** (fixes C and E). Every recurring duty (inspection, warehouse, QC, routing, weekly review, reviews) is a row: *who · what · period · due · status · evidence link*. All dashboards, reminders, sweeps and the Scorecards Overview read the same row, so status can't disagree. A super-admin **Excuse / Credit / Extend** action works on any row with a reason and audit trail — the routing credit we built this week, generalized.
4. **People are records, not text** (fixes D). Pick employees from a list everywhere (vehicles, technicians, inspections, reviews); show "not linked" warnings; merge duplicates once.
5. **Server-saved drafts for every long form** (fixes F). The pattern we just built for the Sales Director review, applied to inspections, audits, reviews, QC.
6. **Role-based homes and nav that match** (fixes G). Each role's home, nav center and bottom bar come from one definition.
7. **Data tasks run at deploy/cron, not on page load** (fixes H) — faster pages and no double-apply risk.

## 5. Benchmark — where CanopyOS stands

Researched against SAP (FSM, SuccessFactors), Salesforce Field Service, ServiceNow FSM/HRSD, Rollins (Orkin; BOSS system), Rentokil Terminix/Ehrlich (PestConnect, myRentokil, "Branch 360"), and PestPac, FieldRoutes/ServiceTitan, Briostack, GorillaDesk. Sources in the researcher's notes below.

**Ahead (for a regional operator):**
- **Manager accountability** — quarterly weighted scorecards tied to bonus, routing/weekly sign-offs, missed-duty strikes, coaching threads. Rentokil (~$4.3B revenue) said in March 2026 it is still *building* "Branch 360" for consistent branch KPIs and daily accountability.
- **Graded, evidence-backed inspections** (vehicle 20-pt with photos, warehouse FL 482/OSHA with e-sign and repeat-finding detection, QC ride-behinds) — not offered by mid-market pest suites.
- **Warehouse receiving/issuing** — AI invoice reading, scan-to-issue, append-only ledger, approval queue: more controlled than PestPac's import + transfers.
- **AI grounded in Clements' own manual/handbook/SOPs**, live today; vendor agent features (WorkWave WAIve, Agentforce) are largely announced or paid add-ons.
- **People operations** (ATS → pre-hire → reviews → write-ups → handbook ack → training) in one phone-friendly app; pest suites stop at the license number.

**Behind:** live data (PestPac arrives as uploads), telematics/driver safety, technician-level performance (callbacks, production/hour), per-person FDACS license & CEU tracking, truck-stock reconciliation, offline field actions.

**Don't build (PestPac or a vendor does it better):** route optimization, technician service app / application records (FAC 5E-14.142), customer portal/notifications/billing, CRM system of record or ML lead scoring, live GPS/dash cams/DVIR, IoT monitoring platform, AI phone answering, payroll, an ERP/HR suite.
