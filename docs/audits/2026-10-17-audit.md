## Full findings by domain

### 1. Navigation, IA & cross-cutting UX
- **Resilience:** no `loading.tsx` (frozen blanks on nav), no `error.tsx`/`global-error.tsx` (unstyled crash), no `not-found.tsx` (21 `notFound()` calls hit the bare default).
- **IA:** "homeless" shared routes (`/inbox`,`/account`,`/help`) fall back to `mode="inventory"` → empty nav for employees + wrong center highlight for managers; 600-line AppShell nav logic with a second `itemsForMode` that can drift; logo isn't a link; ad-hoc back-links in ~49 files, zero breadcrumbs; silent access-redirects with no explanation; redundant Employee Hub button for employees; board-observer bulletin pushed under "More" on mobile.
- **A11y:** no `:focus-visible` except the goal slider; `btn` has no focus ring; active nav is color-only, no `aria-current`; nav dialogs set `aria-modal` but have no Escape/focus-trap; sub-44px mobile top-bar tap targets.
- **Feedback:** only one hand-rolled toast (Access Rights); no shared Toast/Spinner; disabled states are good but no "Saving…" convention.
- **PWA:** offline page is a dead-end (no retry, off-brand tile); `manifest.start_url=/dashboard` dumps non-admins on a page the guard then redirects away from.

### 2. Inventory & Fleet
- **Check-in:** drops unmatched lines silently (#1); no undo (#2); no duplicate-invoice guard (#3); giant unsearchable per-line `<select>` + no scan path (#4); no case→unit helper despite `unitsPerCase` (#5).
- **Check-out (strongest flow):** clearing qty deletes the line (#6); 1..500 option select (#7); uncounted products skip the negative guard with no flag (#8); over-dispense can only escalate, no inline recount (#9).
- **Reconcile:** wrong default warehouse + no on-hand context (#10); unsearchable filters + tiny mobile action links (#11).
- **Stock-count:** silent 60-item cap (#12); no scan-to-count + counts lost on branch switch (#13).
- **Lists:** silent truncation caps across catalog/labels/search/stock-count (#15); History uses `window.prompt` for void reason (#16).
- **Alerts/Dashboard:** low-stock/reorder is read-only with no "start reorder" path (#18); long dashboard + placeholder budget bar up top (#19).
- **Fleet:** no roster search (#20); service silently discards $0/unassigned costed lines (#21); no odometer sanity check (#22); inspection sticky bar collides with mobile nav (#23); long inspection has no draft (#24); two inconsistent driver pickers + contradictory branch-move logic/comments (#25).
- **Strength to preserve:** the check-out scan flow and the inspection segmented controls/live score are genuinely good mobile field UX — bring check-in/stock-count/reconcile up to that bar.

### 3. Management, Executive & Sales
- **Exec IA:** twin "Board/Executive" vs "Executive" dashboards, same audience, overlapping content, inconsistent cross-links, a false in-code claim about which holds the statements (A1); `/management`, `/executive`, `/management/board` are three budget-vs-actual surfaces with duplicated tile code (A2); four differently-labeled AI entry points (A3); `cy_forecast`/`fy`/"Full-Year Forecast" naming mismatch + AI summary silently ignores the forecast basis (A4); weak mobile tables/charts — no sticky first column, 180px SVG label gutters (A5).
- **Sub-pages:** three unreconciled "sales/closed" numbers on adjacent screens (B1); misleading "Sales & Attrition analytics" link (B2); near-empty Insights gate (B3); overloaded board-observer nav incl. ops sync (B4).
- **Sales module:** `/sales/[id]` missing the funnel/diagnosis/coach the advisor sees (C1); `/sales` repeats closed/goal in ~4 widgets, action buried mid-scroll on phones (C2); unlabeled mixed YTD/month "closed" figures (C3); long GoalPlanner with director actions at the extremes (C4); goal-negotiation has 4 states but roster only flags one (C5); FocusPlan uses functional emoji against the brand kit (C6); SalesCenterLive exposes sync/ops controls on an analytics page (C7).

### 4. People/HR, Employee Hub, Training & Onboarding
- **Notifications (dominant):** every lifecycle event is email-only and bypasses the Inbox (A1); training assignment notifies nothing (A2); onboarding submission doesn't notify HR (A3).
- **Onboarding:** approve-and-convert makes a dead-ended hire — no login, no welcome, no onboarding training, while the Hub promises an onboarding checklist nothing populates (B1); packet legal content is live placeholder text inside a signature flow (B2); handbook step degrades silently if unpublished (B3).
- **Employee Hub:** `/me/training` & `/me/library` skip the self-heal link (C1); no self-service contact/emergency edit (C2); "Message HR" doesn't pre-select HR (C3); tech Routine checklist shown to everyone (C4); Inbox card has no unread signal (C5).
- **PTO:** no over-balance warning at request (D1); employee isn't told who approves (D2).
- **Reviews/Training:** field-sign-off rows look broken (status chip, no guidance) (E1); handbook re-ack is manual copy-paste links with no push/bulk (E2); review sign-needed is email-only (E3).
- **Brand:** 📎/✅/✓ emoji in training/review/handbook UI violate the kit (F1).
